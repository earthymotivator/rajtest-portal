# rajtest-portal

A competitive exam portal built with Next.js, App Router, TypeScript, Tailwind CSS, and Supabase.

## Features
- Responsive landing page inspired by competitive exam portals
- Exam categories and test listings
- Exam instructions and live timer
- Bilingual question layouts (Hindi/English)
- Auto-save, question navigation, and result review
- Student dashboard and admin panel
- Secure score validation on the server

## Stack
- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- Supabase PostgreSQL client

## Local setup
```bash
npm install
cp .env.example .env.local
npm run dev
```

## Notes
Set your Supabase environment variables in `.env.local` before running the app.
